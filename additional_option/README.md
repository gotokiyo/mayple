* 各能力値に付与される追加のステータス
* 緑の数字で記載されてるやつ

## 強化方法
* `転生の炎` でオプションを再設定する
* `黒い転生の炎` と、`深淵の転生の炎` だけ現在のオプションと再設定後のオプションをどちらか任意に選択できる。それ以外は、再設定したらもとには戻せない。

## 入手方法
* イベントの出席報酬、イベントのコインショップ、ユニオンのコインショップ、ボスドロップ、etc

## 数値について
* その職業のメインステータスと全ステータスと攻撃力/魔力がいっぱいつくとうれしい
* 各数値の左に記載の数字(tier)が高ければ高いほどうれしい
* 例外はあるけど、最初のうちはとりあえず戦闘力が上がってればよい
